## 🇺🇸 English Version

### 📋 About the Repository
This repository contains a collection of PHP scripts developed during practice sessions to explore fundamental language concepts such as conditional structures, loops, arrays, and functions.

### 🚀 Exercises
1. **Shopping Value Calculator**  
   - **Goal:** Calculate the total purchase value based on price and quantity.  
   - **Concepts:** Arithmetic operators, variables, and `if/else` condition to apply a 10% discount if the total is ≥ R$200.  

2. **School Approval System**  
   - **Goal:** Check student status (Approved or Failed).  
   - **Concepts:** Logical operators (`&&`), arithmetic averages, and conditional structures based on grades (≥ 6) and absence limits (≤ 15).  

3. **Interactive Multiplication Table**  
   - **Goal:** Generate the complete multiplication table for a chosen number (1 to 10).  
   - **Concepts:** `for` loop, counters, and string interpolation.  

4. **Class Grade Manager**  
   - **Goal:** List grades, identify positions, calculate class average, and find highest/lowest grades.  
   - **Concepts:** Arrays, `foreach` loop, and native PHP functions (`array_sum()`, `max()`, `min()`, `array_search()`).  

5. **BMI Calculator with Functions**  
   - **Goal:** Calculate Body Mass Index (BMI) and display health classification.  
   - **Concepts:** Custom functions with parameters, argument passing, numeric formatting (`number_format()`), and conditional chains (`if/elseif/else`).

## 🇧🇷 Versão em Português

### 📋 Sobre o Repositório
Este repositório contém uma coleção de scripts em PHP desenvolvidos durante as aulas para praticar conceitos fundamentais da linguagem, como estruturas condicionais, laços de repetição, arrays e funções.

### 🚀 Exercícios
1. **Calculadora de Valor de Compra**  
   - **Objetivo:** Calcular o valor total de uma compra com base no preço e quantidade.  
   - **Conceitos:** Operadores aritméticos, variáveis e condição `if/else` para aplicar desconto de 10% caso o total seja ≥ R$200.  

2. **Sistema de Aprovação Escolar**  
   - **Objetivo:** Verificar a situação acadêmica do aluno (Aprovado ou Reprovado).  
   - **Conceitos:** Operadores lógicos (`&&`), médias aritméticas e estruturas condicionais baseadas em notas (≥ 6) e limite de faltas (≤ 15).  

3. **Tabuada Interativa**  
   - **Objetivo:** Gerar a tabuada completa de um número específico de 1 a 10.  
   - **Conceitos:** Laço de repetição `for`, contadores e interpolação de strings.  

4. **Gerenciador de Notas da Sala**  
   - **Objetivo:** Listar notas, identificar posições, calcular a média da turma e encontrar as maiores e menores notas.  
   - **Conceitos:** Arrays, laço `foreach`, e funções nativas do PHP (`array_sum()`, `max()`, `min()`, `array_search()`).  

5. **Calculadora de IMC com Funções**  
   - **Objetivo:** Calcular o Índice de Massa Corporal (IMC) e exibir a classificação de saúde correspondente.  
   - **Conceitos:** Criação de funções personalizadas com parâmetros, passagem de argumentos, formatação numérica com `number_format()` e encadeamento de `if/elseif/else`.
